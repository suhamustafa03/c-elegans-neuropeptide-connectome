CONCLUSION
======================================================================
The strict both-neurons-held-out split uses roughly 1/n_splits of all pairs as test
data per fold and drops the rest (straddling pairs) from that fold's training set too -
this is the correct primary evaluation, but discards real data. The
stimulated-neuron-only split retains every pair in some fold's test set, at the cost of
letting downstream neurons repeat between train and test. Both are reported on the real
propagation target once obtained, with the strict split as the primary, trusted number
and the stimulated-only split as a secondary, explicitly-weaker comparison - never a
silent substitute.
