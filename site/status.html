Built, tested, and run on real data

  • License-clear substitute dataset found and independently verified (Zenodo 8185377 v2, CC BY 3.0 US) after the original propagation data's reuse terms proved unresolved.
  • 80 real recordings downloaded, MD5-verified, and structurally inspected (neuron counts, timing, behavior channels, missingness) before any modeling.
  • Time-aware gap segmentation, purge-gapped blocked and forward-chaining cross-validation, population-level neural features — all implemented in src/behavior_forecast/ and unit-tested (tests/test_behavior_forecast_segments.py) before running on real data.
  • Full analysis run on all 80 recordings, both CV schemes, both marker-free and marker-present groups — see Results.
  • 90 unit tests total, all passing (python -m pytest tests/ -q), including dedicated tests for the forecasting pipeline's features, models, metrics, and the paired-comparison analysis — not just the windowing/leakage logic.

Earlier direction: neuropeptide connectome & signal propagation — Paused

The project originally asked whether an inferred neuropeptide connectome improves prediction of measured signal propagation (Randi et al. 2023 data). That data's reuse terms were ambiguous (full review in docs/DATA_LICENSES.md §3a) and a permission request to the corresponding author went unanswered; rather than use the data without a clear license or wait indefinitely, the project pivoted to the behavior-forecasting question described throughout this site. This earlier direction is paused, not completed and not abandoned — it may be resumed if licensing is resolved. What was built for it:

  • Two connectivity layers fetched, cleanly MIT-licensed, committed (White 1986 synaptic/gap-junction; Ripoll-Sanchez et al. neuropeptide connectome).
  • Neuron-ID alignment across conflicting naming conventions (300/302 verified, 2 explained).
  • Leakage-aware neuron-grouped cross-validation, audited against real connectome structure as a stand-in label (not propagation data) — see the repository's results/split_audit_dry_run.txt.
  • Baseline models, nested-CV hyperparameter selection, a degree-preserving null model, and an explicitly provisional/uncalibrated bootstrap — all built and unit-tested on synthetic fixtures or structural stand-in data, never on real propagation data, because that data was never obtained.

This infrastructure is not used by, and makes no contribution to, the behavior-forecasting results reported elsewhere on this site. It is documented here only so the project's history is honest and traceable.

Not yet done (behavior-forecasting study)

  • Only one fixed forecast horizon (5s) and history window (10s) were tested; a horizon-sensitivity sweep was not run.
  • The 11 scrambled-control files were not used as a verified negative control (their exact intended role wasn't independently confirmed).
  • No nonlinear model was compared against the ridge/logistic baselines.
