Reproducibility

Setup, running the tests, and reproducing the behavior-forecasting analysis.

Setup

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

This project's own requirements.txt intentionally does not include h5py — reading the raw .h5 recordings is kept to a separate, throwaway environment outside this repository, since the raw data itself is never committed (see Data).

Run the tests

PYTHONPATH=src python -m pytest tests/ -q

90 tests total: 52 covering the active behavior-forecasting study on deterministic synthetic fixtures — gap segmentation, purge-gapped blocked/forward-chaining folds, feature extraction, models (including the single-class classifier fallback), metrics (including the undefined-PR-AUC case), the end-to-end per-recording pipeline, and the paired-comparison analysis — plus the 38 original tests for the paused connectome project's infrastructure (neuron-ID alignment, split strategies, models, evaluation, nulls) on real connectome data or synthetic fixtures. None run on the real behavior-forecasting recordings themselves, since those are kept outside Git; load_recording (the one function that reads real .h5 files) is intentionally not unit-tested for the same reason.

Reproducing the behavior-forecasting analysis

  1. Download processed_h5.tar.bz2 from Zenodo record 8185377, v2 (747,188,437 bytes) to a location outside this repository, and verify its MD5 (f76bb089208db62eb4dd30785b525eda).
  2. Extract it, and in a separate, isolated environment (not this project's own .venv) install h5py, numpy, pandas, and scikit-learn.
  3. Run the pipeline in src/behavior_forecast/pipeline.py (run_recording, load_recording) against each extracted .h5 file, using that isolated environment's Python so it can import src/behavior_forecast alongside h5py.
  4. Aggregate per-recording results (median/IQR across recordings, split by marker-free vs. marker-present and by CV scheme) — see docs/BEHAVIOR_FORECAST_RESULTS.md for the exact protocol this repository's own run followed.

The full, exact numeric output from this repository's own run is committed at results/behavior_forecast_summary.txt — only the aggregated, recording-level summary statistics, never raw per-frame or per-neuron data.

Reproducing the paused connectome project's infrastructure

python src/fetch_connectomes.py
python src/audit_splits.py

Fetches the two MIT-licensed connectivity layers and reproduces results/split_audit_dry_run.txt (a structural stand-in audit, not a propagation-data result). See Status for why this direction is paused.
